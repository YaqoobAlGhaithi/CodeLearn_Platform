# CodeLearn — منصة تعليمية للبرمجة

منصة ويب عربية موجهة للمبتدئين لتعلم البرمجة بصورة تفاعلية. تجمع المنصة بين المسارات التعليمية، الدروس العملية، محرر كود في المتصفح، تتبع التقدم، الإنجازات، ومنتدى النقاش.

## المزايا الرئيسية

| المجال | المزايا المتوفرة |
| --- | --- |
| التعلم | مسارات في HTML وCSS وJavaScript وReact، مع دروس وأمثلة برمجية. |
| التفاعل | محرر Monaco لتجربة الأكواد مباشرة، ونظام لتتبع تقدم الدروس. |
| المجتمع | منتدى للمواضيع والتعليقات والأسئلة بين المتعلمين. |
| الحسابات | مصادقة مستخدمين جاهزة، ولوحة تحكم وإنجازات وشارات. |
| المعلومات | صفحات عن المنصة، تواصل، أسئلة شائعة، خصوصية، شروط استخدام، رعاية، دعم، وإبلاغ عن مشكلة. |

## التقنيات

يستخدم المشروع React 19 وTypeScript وVite للواجهة، وExpress وtRPC للخادم، وDrizzle ORM مع MySQL/TiDB لطبقة البيانات، إضافة إلى Tailwind CSS وMonaco Editor.

## التشغيل المحلي

### المتطلبات

يتطلب المشروع Node.js 22 أو أحدث وpnpm. كما يحتاج إعداد متغيرات بيئة المصادقة وقاعدة البيانات وفق بيئة التشغيل.

### الأوامر

```bash
pnpm install
pnpm db:push
pnpm dev
```

يفتح خادم التطوير المنصة محلياً بعد التنفيذ. ويمكن التحقق من الكود والاختبارات وبناء الإنتاج عبر:

```bash
pnpm check
pnpm test
pnpm build
```

## بنية المشروع

```text
client/          واجهة React والصفحات والمكونات
server/          خادم tRPC وطبقة قاعدة البيانات والاختبارات
drizzle/         مخطط قاعدة البيانات والهجرات
shared/          الأنواع والدوال المشتركة
```

## الخصوصية والأسرار

لا تتضمن المستودعات ملفات البيئة أو مفاتيح الوصول. استخدم ملف إعدادات بيئتك الخاصة عند النشر أو التشغيل المحلي.
